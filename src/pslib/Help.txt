eMerger (Windows) - one-command system updater
Lists every flag of up on Windows, the variables config.ps1 and the
environment set, the config and state files and the exit codes. The options
object config.ps1 can also set: doc/documentation.pdf.

USAGE
  up [options] [--]

GENERAL
  -h, --help                Show this help
  -V, --version             Show version
      --doctor              Run environment health check

EXECUTION
  -n, --dry-run             Show what would be done, do nothing
  -v, --verbose             Stream pkg-manager output live
  -q, --quiet               Quieter by one level per use: no info lines
  -qq, -qqq                 Summary line only, exit code only
  -y, --yes                 Assume "yes" on prompts
      --json                Machine-readable run summary on stdout
      --reboot              Reboot if the system requires it
      --reboot-exit         Exit 4 instead of 0 when a reboot is required
      --                    End of options: the words after it are ignored
      Short flags from the set h V n v q y w bundle: -nv == -n -v
      A value flag also takes --flag=VALUE: --only=winget,scoop

SELECTION
      --security            Security updates only: Windows Update; every other
                            manager has no security channel and is skipped
      --accept-licenses     Let winget, choco and Windows Update accept licence
                            agreements; without it they only list updates
      --dev                 Include dev toolchains (rustup, cargo, npm, pnpm, pip, gem)
      --only LIST           Comma-separated managers to keep (e.g. winget,scoop)
      --except LIST         Comma-separated managers to skip (adds to the profile's list)
      --profile NAME        Load profiles.d\NAME.ps1, else the shipped share\profiles\NAME.ps1
      --list-profiles       List available profiles

DISPLAY
  -nl, --no-logo            Hide logo
  -ni, --no-info            Hide system info line
      --ascii               ASCII glyphs only
  -w,  --weather            Show weather line via wttr.in
      (env) EMERGER_EMOJI=auto|1|0, EMERGER_SPINNER=braille|dots|pulse|line,
            EMERGER_PROMPT_TIMEOUT=60 (seconds), NO_COLOR, COLORFGBG

CLEANING
  -nc, --keep-cache         Skip %TEMP% cleaning
  -nt, --keep-trash         Skip recycle bin

INSPECTION
      --history             Last runs
  -err, --errors            Tail of logged errors
      --metrics FILE        Export last run as Prometheus textfile

MAINTENANCE
  -up,  --self-update       Update eMerger via git (fast-forward)
  -au,  --auto-update       Register weekly Task Scheduler entry
  -rc,  --rebuild-cache     Accepted; Windows keeps no detection cache

NOT AVAILABLE ON WINDOWS
  --changed --changelog --rollback
                            Print a warning and exit 0, nothing is updated
  --firmware --no-firmware --snapshot --parallel --resume --download-only
  --deep-clean --refresh-mirrors
                            Print a warning, the run goes on without them

EXAMPLES
  up                        # normal run (UAC prompt for choco/wsl/Windows Update)
  up -n                     # preview
  up --security -y --accept-licenses   # unattended, security-only Windows Update
  up --dev                  # include rustup/npm/pip/gem
  up --only winget,scoop    # limit to specific managers
  up --profile work         # named profile

CONFIG
  %APPDATA%\emerger\config.ps1           Dot-sourced before argument parsing
  %APPDATA%\emerger\profiles.d\*.ps1     User profiles
  %APPDATA%\emerger\hooks\pre.d\*.ps1    Pre-update hooks
  %APPDATA%\emerger\hooks\post.d\*.ps1   Post-update hooks
  Thresholds in config.ps1: $script:DISK_MIN_FREE_MB (1024),
  $script:BATTERY_MIN_PCT (20), $script:RETRY_ATTEMPTS (2),
  $script:RETRY_DELAY (3),
  $script:MANAGER_TIMEOUT (0; seconds per manager step, 0 = no limit),
  $script:UI_VERBOSE ($false, as -v), $script:QUIET_LEVEL (0, as -q)

STATE
  %LOCALAPPDATA%\emerger\state\emerger.log     Log
  %LOCALAPPDATA%\emerger\state\history.jsonl   Run history
  %LOCALAPPDATA%\emerger\state\run.lock        Run lock, one run at a time
  %LOCALAPPDATA%\emerger\state\elevated.lock   Lock the elevated child holds

EXIT CODES
  0  success
  1  runtime failure or aborted (a declined safety prompt)
  2  argument parsing error
  3  one or more package managers failed
  4  reboot required (only with --reboot-exit)
